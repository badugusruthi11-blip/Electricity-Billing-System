## Electricity Billing System

## Project Overview

The Electricity Billing System is a simple software application designed to manage electricity usage records and generate bills for customers.
It helps utility companies or administrators automate billing processes, reduce manual errors, and maintain accurate customer payment records.
This project is built as a single application system that handles customer details, meter readings, bill calculation, and bill generation in a structured way.

## Objective

1.The main objective of this project is to:
2.Automate electricity bill generation
3.Store and manage customer information
4.Calculate electricity charges based on unit consumption
5.Maintain billing history for records and reference

## Working Process

1.Admin adds customer details into the system
2.Meter readings are entered for each billing cycle
3.System calculates units consumed
4.Bill is generated based on tariff rates
5.Final bill is displayed or stored for printing

## How to Run

Clone or download the project
Open project in IDE (Eclipse / VS Code / PyCharm etc.)
Compile the source code
Run the main file
Follow on-screen instructions
